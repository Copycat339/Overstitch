# Overstitch

**Overstitch** es una tienda online de Hoodies oversize, con enfoque en sudaderas personalizadas bordadas y prendas únicas.

## Objetivo
Crear una experiencia de compra moderna para ropa personalizada, enfocada en la calidad, diseño y personalización.

## Estado actual
Proyecto en desarrollo. Se agregan avances semanalmente según la planificación del curso.

---

## ✅ Avances al 22 de mayo de 2025

- Se completó la maquetación inicial del sitio web con HTML y CSS.
- Se integró navegación entre secciones: **Inicio**, **Productos**, **Personaliza** y **Contacto** usando JavaScript.
- Se creó la sección de **Productos**:
  - Se agregaron dinámicamente 17 productos de prueba mediante `JavaScript`.
- Se desarrolló la sección **Personaliza tu prenda**:
  - Formulario con selección de tipo de personalización (`texto`, `imagen`, `bordado`).
  - Campos para descripción, subida de imagen, color de bordado y botón de envío.
  - Estilos personalizados con CSS (interfaz intuitiva y minimalista).
  - Funcionalidad básica: alerta de confirmación al enviar.
- Se mejoró la estructura de carpetas (`assets`, `scripts`, `styles`).
- Preparación para conexión con Supabase (próximos pasos).
- Código modular y limpio en `index.html`, `styles.css` y `main.js`.
